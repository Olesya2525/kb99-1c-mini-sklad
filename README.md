# Мини-Склад (kb99, неделя 1)

Учебная конфигурация **1С:Предприятие 8.3**: справочники `Товары`, `Контрагенты`; документы `Поступление`, `Реализация`; подсистема «Мини-Склад».

## Что в репозитории

- `src/` — выгрузка конфигурации **в файлы** (Конфигуратор → Выгрузить конфигурацию в файлы).
- `src/1Cv8.cf` — та же конфигурация одним файлом (на всякий случай).

Данных пользователей (товары, документы) в git нет, только структура.

## Как открыть

1. Установите платформу **1С:Предприятие 8.3**.
2. Создайте пустую файловую информационную базу.
3. Конфигуратор → **Конфигурация → Загрузить конфигурацию из файлов…** → укажите папку `src`.
4. Обновите конфигурацию базы данных, запустите **1С:Предприятие** (F5).

Либо: **Конфигурация → Загрузить конфигурацию из файла…** → `src/1Cv8.cf`.
